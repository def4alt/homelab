## Obsidian knowledge policy

- Use the Obsidian vault as the long-term source of truth for durable facts, decisions, project context, and memory.
- Search the vault before answering from memory when the answer may already exist in notes.
- When the user asks to remember, capture, summarize, or update knowledge, write it to Obsidian instead of keeping it only in chat.
- Cite relevant note paths when an answer comes from the vault.
- Keep chat memory short-term; treat Obsidian as the durable knowledge base.
